# ERP System Release Note_2026 07 5주차

기간: 2026-07-27 ~ 2026-07-31

## 요약

- 타임시트 메뉴가 프로젝트 단위 그룹과 세부 업무 입력 구조로 개편되었고, 주말/공휴일 입력 제한과 월 마감 제어가 추가되었습니다.
- 타임시트 관리자 인건비 배부 화면에 프로젝트별 인건비 산출, 공사/기타 매출 그룹별 금액 비교, 구매계획 인건비 연동 기능이 추가되었습니다.
- 설계 의뢰, 견적, 프로젝트, 매출/매입 청구, 구매/계약, 출고 요청 등 주요 업무 목록에 읽기 전용 상세 조회 화면이 추가되었습니다.
- PC 해상도별 반응형 UI 기준 문서가 추가되고, 테이블/모달/상세 조회 화면의 공통 사용 규칙이 정리되었습니다.

## 메뉴별 변경 사항

### 타임시트

#### 기능 수정 사항

- 주간 타임시트 입력 화면을 기존 행 단위 입력에서 프로젝트 그룹 + 세부 업무 구조로 개편했습니다.
  - 프로젝트별로 세부 업무를 여러 건 등록할 수 있습니다.
  - 프로젝트 그룹 접기/펼치기, 전체 접기/펼치기, 업무 추가, 프로젝트 추가 기능이 추가되었습니다.
  - 프로젝트별 요일 합계와 주간 합계가 그룹 헤더에서 바로 보이도록 정리되었습니다.
- 주말 및 공휴일 입력을 제한했습니다.
  - 화면에서 주말/공휴일 날짜를 표시하고 해당 날짜의 시간 입력을 비활성화합니다.
  - 저장 시에도 서버에서 주말/공휴일 입력 여부를 재검증합니다.
- 타임시트 목록과 팀 현황 조회 시 실제 입력 시간, 총 시간, 입력 건수 기준으로 정렬 우선순위를 보강했습니다.
- 일정 메뉴에서 출장/휴가성 일정이 타임시트로 동기화될 때 주말과 공휴일은 제외되도록 수정했습니다.
- 실행 프로젝트 텍스트 입력 시 프로젝트 번호 또는 프로젝트명으로 기존 실행 프로젝트를 자동 매칭하도록 보강했습니다.
- 월별 조회와 요약 계산에서 주말/공휴일 입력값을 제외하도록 정리했습니다.
- 화면 초기 로딩, 직원 선택, 주간 데이터 로딩의 비동기 순서를 보강해 이전 요청 결과가 뒤늦게 화면에 반영되는 현상을 줄였습니다.

#### 기술적인 내용

- `timesheet_labor_allocations` 테이블에 공사/기타 구분별 비율금액, 실제금액, 차이금액 컬럼이 추가되었습니다.
  - `contract_ratio_amount`, `contract_actual_amount`, `contract_diff_amount`
  - `other_ratio_amount`, `other_actual_amount`, `other_diff_amount`
- 신규 마이그레이션 `20260730_0015_timesheet_labor_close.py`가 추가되었습니다.
  - `timesheet_monthly_closes` 테이블을 생성합니다.
  - 월별 타임시트 마감 상태, 마감자, 마감일시를 저장합니다.
- 스키마 보정 유틸리티도 동일 컬럼과 월마감 테이블을 보장하도록 확장되었습니다.
- 관리자 인건비 API가 계산 로직과 저장 로직으로 분리되었습니다.
  - `GET /timesheets/admin-labor`: 인건비 배부 및 프로젝트별 인건비 계산 조회
  - `POST /timesheets/admin-labor`: 배부 금액, 프로젝트별 월 인건비 저장 및 월 마감 처리
- 인건비 배부 저장 시 프로젝트별 월 인건비가 `ProjectPurchasePlanRow`의 `labor_cost_N월` 필드와 `labor_cost_total`에 반영됩니다.
- 월 마감된 타임시트는 일반 사용자가 수정할 수 없고, 관리자 권한은 예외 처리됩니다.
- 공휴일 정보는 `Holiday` 테이블을 기준으로 조회하며, 서버 저장 검증과 프론트엔드 입력 제한 모두에서 사용됩니다.
- 매출 유형은 공사 계열과 기타 계열로 분류되어 인건비 배부 계산에 사용됩니다.
  - 공사 계열: 공사, 공사진행율, 상품매출, 시운전
  - 기타 계열: 유지보수, 서비스

### 타임시트 관리자 인건비 배부

#### 기능 수정 사항

- 인건비 배부표가 총액, 공사비율, 공사실제, 공사차이, 기타비율, 기타실제, 기타차이를 비교할 수 있도록 확장되었습니다.
- 프로젝트별 인건비 테이블이 추가되어 프로젝트별 월별 인건비와 누계 인건비를 확인하고 조정할 수 있습니다.
- 인건비 저장 시 배부 결과와 프로젝트별 월 인건비가 함께 저장되며 해당 월은 마감 처리됩니다.

#### 기술적인 내용

- 급여, 상여, 퇴충 카테고리별 총액을 기준으로 공사/기타 그룹 비율금액을 계산합니다.
- 프로젝트별 실제 인건비 합계를 카테고리 총액 비중으로 나누어 실제금액을 계산하고, 비율금액과 실제금액의 차이를 별도 컬럼으로 산출합니다.
- 저장된 수동 조정값이 있으면 자동 계산값보다 저장값을 우선 표시합니다.
- 프로젝트별 월 인건비는 구매계획 행과 upsert 방식으로 동기화됩니다.

### 설계 의뢰

#### 기능 수정 사항

- 설계 의뢰 목록 행 클릭 시 읽기 전용 상세 조회 모달을 열 수 있도록 변경했습니다.

## 배포/운영 참고사항

- DB 마이그레이션 `20260730_0015` 적용이 필요합니다.
  - `timesheet_labor_allocations` 컬럼 추가
  - `timesheet_monthly_closes` 테이블 및 인덱스 생성
- 타임시트 월마감 기능이 활성화되므로, 운영자는 월별 인건비 배부 저장 시 해당 월이 마감 처리되는 업무 흐름을 사용자에게 안내해야 합니다.
- 공휴일 입력 제한은 `Holiday` 테이블 데이터에 의존합니다. 공휴일 마스터가 누락되면 해당 날짜가 평일처럼 처리될 수 있습니다.
- 프로젝트별 인건비 저장은 구매계획 데이터의 월별 인건비 필드를 갱신합니다. 배포 전 기존 구매계획 데이터와 운영 보고서 산식의 영향 범위를 확인하는 것이 좋습니다.
- 신규 상세 조회 화면은 여러 메뉴의 행 클릭 동작을 바꿉니다. 기존에 행 클릭으로 바로 수정 폼을 열던 사용자는 이제 상세 조회 후 수정 버튼을 눌러야 합니다.
- 프론트엔드 API에 `getProfitLossData(year)` 호출 함수가 추가되었으나, 이번 변경 범위에서 해당 호출부 사용 여부는 확인되지 않았습니다.
